# 纯阅 Pure Novel

手机优先的个人小说阅读器。Python 3.11+ 标准库后端，原生 HTML/CSS/JavaScript 前端；主服务无需第三方依赖。

支持本地独立运行，或使用自己的 Vercel + Supabase 部署邀请制同步实例。项目不提供公共服务、共享账号、预置书库或数据库凭据。

## 本地运行

下载仓库 ZIP 解压或克隆仓库，在项目根目录运行：

```sh
python --version
python reader.py
```

打开 http://127.0.0.1:8000 。部分系统使用 `python3`。保持终端运行，Ctrl+C 停止。不要直接双击 HTML 或使用纯静态服务器。

未配置 Supabase 且不在 Vercel 时使用无账号本地模式；之前配置过认证环境变量的，请先移除。程序**不会自动读取 .env**。

同一 Wi-Fi 下手机访问：

```sh
python reader.py --host 0.0.0.0 --port 8000
```

手机打开 `http://电脑局域网IP:8000`，必要时仅允许 Python 的专用网络入站连接。**不要向公网开放无账号开发服务。** 普通局域网 HTTP 不保证文件导入、PWA 和离线体验；完整体验需 HTTPS 或 localhost。

## 使用与限制

- 输入完整书名，检查来源并选择后开始阅读；也可粘贴有权访问的具体目录或章节 URL，而非站点首页。
- 搜索尝试 Bing、360、百度、搜狗公开网页，并非稳定搜索 API 或穷尽全网。改版、验证、403、网络出口和跳转都可能使入口不可用。查看详情或直接提供合法公开链接。
- 首次自动检查最多 8 个网站，主动继续寻找可检查更多新网站，找到两个样本可读网站后暂停。样本通过不代表全书完整、免费、授权或长期可用。同名作品需人工核对。
- 解析常见 HTML 正文、目录与分页，不支持任意网站、图片正文或必须执行源站 JavaScript 的内容。不绕过付费、登录、验证码或 DRM。
- 阅读时点“Aa 设置”可选择纸白、暖杏、豆沙绿、雾灰、浅蓝五种日间配色，或手动切换夜读；豆沙绿标为“护眼推荐”，仅代表配色偏好，不承诺医学效果。切色保留字号、行距和阅读位置，选择按现有规则保存在本机并同步。
- 最近完整章节保存在本机 IndexedDB；预取最多同源下一章，不批量下载全书。服务端完整章节缓存五分钟，“重新获取本章”仅绕过浏览器缓存。
- 读取、搜索与来源检查共用单次 45 秒处理预算，浏览器在 55 秒取消仍未完成的请求。分页不完整会显示警告且不缓存；搜索没有候选结果时不缓存，有结果时缓存两分钟，同书名重试仍受请求配额限制。
- 手动导入最多 24 MiB 无 DRM 文字 EPUB / TXT，预览后确认。不支持 PDF、MOBI、AZW3、加密 EPUB 或格式转换。编码推测可能不准。
- 目录及导入正文保存在本机 IndexedDB；书架、设置和进度以轻量元数据保存。电子书按章读取，清理浏览器数据会丢失正文，需自行备份原文件。
- 云端仅同步书架元数据、设置和进度，不同步正文、大目录。其他设备需重新导入相同文件。同步为整份书架版本化保存，冲突需选择版本，非实时订阅。
- 本地无账号模式在成功联网确认模式并缓存应用外壳后，可断网刷新或停止后端后继续阅读本机电子书、已缓存章节和目录；未缓存内容仍需联网。通过离线提示中的“重新连接”恢复服务。
- 账号模式在本设备成功登录或联网验证后，自动允许离线阅读 7 天；只有本设备已保存的正文、目录与书架可用。断网刷新后继续读，进度先存本机，联网重新验证为同一账号后再同步；版本冲突仍需选择保留哪份。
- 离线资格过期需联网验证，不删除原书；明确的登录失效或成员停用会撤销资格。离线时无法即时得知云端停用；共享设备上的本机副本也可被设备使用者访问。退出会清除此账号本机数据；离线退出将在下次联网时先撤销服务端会话。
- 从未成功验证、已退出或过期的账号，不能离线重启书架。首次访问即离线、普通局域网 HTTP、浏览器清理或回收存储时不保证离线可用。

## 本机存储升级

新版自动把旧书架内的目录移入 IndexedDB；旧电子书首次打开时逐本迁移为按章存储。核验成功后才清理对应旧数据，原章节地址、书籍身份和进度保留。空间不足或升级失败时保留旧格式并提示重试，不需要先删除原书。

升级被旧标签页阻挡时，关闭其他纯阅标签页再刷新。迁移期间暂时需要容纳新旧两份正文；请保留原 EPUB / TXT 文件。新版数据库不能直接用只支持旧结构的脚本打开，回退程序前应先确认数据库兼容性，不要通过清库解决升级问题。

## 自行部署

见 [DEPLOY.md](DEPLOY.md)：准备自己的 Supabase、执行迁移、创建成员，再部署到 Vercel。无需维护者项目或聊天助手在线。

若大陆网络无法打开平台默认域名，可按 [免费备用入口说明](DEPLOY.md#8-render-免费备用入口试验)试验 Render。仓库的 [render.yaml](render.yaml) 只创建一个免费、强制认证且不连接数据库的候选服务；需先在实际无 VPN 网络确认可达，再配置原 Supabase。此入口尚未通过大陆直连验收，不保证免费域名长期可达，遇到收费或绑卡要求即停止。

换网址后需重新登录；云端已同步的书架和进度可恢复，本机电子书需重新导入同一文件。不同网址的 Cookie、离线资格与正文缓存不能自动迁移。

## 测试

在项目根目录运行：

```sh
python -m unittest discover -s tests -v
node --check public/app.js
node --check public/ebooks.js
node --check public/storage.js
node --check public/sw.js
```

单元测试不依赖外网。浏览器模拟冒烟需 Node.js 22+、Edge / Chromium 和运行在 8000 端口的本地服务：

```sh
node tests/browser-smoke.mjs
```

可用 `BROWSER_PATH` 指定浏览器、`READER_URL` 指定本地测试服务地址（默认 `http://127.0.0.1:8000/`）。测试使用独立浏览器配置和临时调试端口，覆盖大目录、迁移中断/回滚、分章读取、本地离线、账号七天资格、重连验证/同步冲突、离线退出，以及六种阅读配色的可读性、阅读位置和保存同步。仅验证配色时，可设置 `READER_SMOKE_CHECKS=themes` 后运行同一脚本；不设置则运行完整回归。测试内容和云端 API 为受控模拟，不代替真实来源、Supabase、Vercel 构建或手机验收。可选线上测试见部署指南。

## 文件

- `reader.py`、`request_budget.py`、`observability.py`：HTTP 服务、有界请求、脱敏分段指标、安全抓取、搜索与正文解析。
- `public/`：界面、导入、书架、缓存和 PWA；`storage.js` 管理目录、分章正文与旧数据迁移。
- `cloud.py`：认证、成员检查、同步和配额。
- `api/index.py`、`vercel.json`：Vercel API 函数、静态分发与区域配置。
- `pyproject.toml`、`uv.lock`：无第三方运行依赖的 Python 构建清单；部署版本由 `.python-version` 指定。
- `supabase/migrations/`：表、RLS 与函数。
- `setup_account.py`、`manage_user.py`：管理员本地开户。
- `tests/`：单元测试、模拟浏览器及可选联网诊断。

`acquire.py`、`openbooks.py`、`publications.py` 及部分历史测试为实验模块，不代表当前首页功能。主服务不需要 `requirements-assistant.txt`；历史自动获取脚本不属于启动或部署步骤。
